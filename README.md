# c57

Low-cost bluetooth devboard

![](assets/3d.png)

Features:
- Low-cost wch antenna
- On board antenna 
- Bootloader via USB
- Bare metal
- A lot of gpio
- on board usb c

![](assets/schem.png)

This devboard lets you do low cost and low powered bluetooth communications. Best used with ch32fun
